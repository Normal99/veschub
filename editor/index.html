Getting Started

  1. Drag widgets from the left panel onto the canvas
  2. Select a widget to edit its properties in the right panel
  3. Bind widgets to VESC data sources for live updates
  4. Create multiple screens using the bottom panel
  5. Export your dashboard as JSON to use on mobile
